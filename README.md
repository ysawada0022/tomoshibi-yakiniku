# 炭火焼肉 燈火 -TOMOSHIBI- — 新規オープン集客LP / ポートフォリオ作品

大阪・福島に新規オープンする架空の焼肉店「炭火焼肉 燈火（ともしび）」の集客用ランディングページです。
**オープン前**という状況に固有の課題 — 実績も口コミもクチコミサイトの点数もまだ無い状態で、
どうやって初回来店とWEB予約を取るか — を主題にして制作しています。

## デモの見方

`index.html` をブラウザで開くだけで動作します（ビルド不要）。
画像はダウンロード済みでローカル参照のため、CDN（Bootstrap等）以外はオフラインでも表示されます。

## オープン前のLPとして意識したこと

実績・口コミ・行列写真といった「後から積み上がる素材」が一切使えない前提で組み立てています。

- **信頼の代わりに、具体を置く** — 「美味しい」ではなく「芯タンのみ10mm」「トモバラは筋を外して4mm」「ハラミは30日」。
  数字と手順で語れば、食べたことがなくても判断できます
- **今動く理由をつくる** — カウントダウンと「オープン週はすでに埋まりはじめています」の一文、
  そして期限つきの4特典。オープン前LPで最も効く要素だと考えています
- **幹事の不安を先に潰す** — 宴会は「いくらになるか分からない」ことが最大の障壁なので、
  見積もりシミュレーターを料金表のすぐ下に置きました
- **差別化を1行に圧縮する** — 「一人に一台、七輪を。」。
  近隣との比較で選ばれるには、覚えて帰れる一言が要ると考えました

## この作品で見せたいこと

1本目のLP（FORMA・パーソナルジム）は明るい配色の即断即決型、2本目（CODEBRIDGE・ITスクール）は
濃紺×バイオレットの検討期間が長いオンライン商材でした。
本作は**墨黒 × 炭火の朱 × 金の和モダン**、**実店舗・オープン前**という、どちらとも異なる文脈を選んでいます。

### 部位図（本作の目玉 1）

牛のイラストを**インラインSVGで自作**し、9つの部位を選べるようにしました。画像ではないので、
拡大しても崩れず、配色はCSS変数だけで変えられます。

- 部位ごとに「扱い」と「お品書き」を出し分け。図とお品書きの金額は看板メニューと同じ値
- SVGの `<g>` はボタン要素ではないため、`role="button"` / `tabindex` / Enter・Space のキー操作を自前で実装
- スマホでは図が小さくタップしづらいので、下にチップ型のボタンを並べて同じ操作ができるようにしています
- JavaScriptが動かない環境でもチップと初期表示（タン）は残ります

### 宴会の見積もりシミュレーター（本作の目玉 2）

FORMAの「入力すると数値が変わる」、CODEBRIDGEの「多段階クイズ」とは別の方向として、
**キャンペーン条件が計算結果に反映される**タイプにしました。

- 人数 × コース × 飲み放題 → 合計とお一人あたりを表示
- 10名以上で「幹事様1名分が無料」が自動で適用され、値引き行が現れる
- 4名未満 / 4〜9名 / 10〜19名 / 20名以上 でコメントが4分岐し、
  「あと◯名で何が無料になるか」を提示して人数の上積みを促す
- **飲み放題は人数分いただく**（無料になるのはコース料金のみ）といった条件も計算に含めています

### カウントダウン

`new Date('2026-11-01T17:00:00+09:00')` のようにタイムゾーンを付けて基準時刻を指定しているため、
閲覧者の端末がどの地域に設定されていても同じ時刻を指します。
オープン日を過ぎた場合は数字を出さず、一文に差し替わります。

### 周辺図

Google Maps の埋め込みではなく、**SVGで簡略図を自作**しました。
線路・国道・なにわ筋・目印を置き、駅からの徒歩ルートを道路の上だけを通るように引いています。
外部サービスに依存しないため、読み込みが速く、配色もサイトに合わせられます。

- [Bootstrap Icons 1.11](https://icons.getbootstrap.com/)（CDN）
- [AOS 2.3](https://michalsnik.github.io/aos/)（CDN）— スクロール連動アニメーション
- Google Fonts（Shippori Mincho / Cormorant Garamond / Noto Sans JP）
- インラインSVG（部位図・周辺図）
- 画像は [Pexels](https://www.pexels.com/) からダウンロードし、`assets/img/` に同梱（オフラインでも表示可能）

## 実装のポイント

- **BEM 記法** — `block__element--modifier`。レイアウトは `l-`、JS参照は `js-`、汎用は `u-` で責務を分離
- **CSS 設計** — 配色・角丸・影・フォントを `:root` のカスタムプロパティに集約
- **料金の一元管理** — コースと飲み放題の金額は `main.js` の `COURSES` / `DRINKS` にまとめ、
  キャンペーンの適用人数（4名・10名・20名）も定数化。料金表・キャンペーン・シミュレーターの
  3箇所で数字がずれないようにしています
- **予約ウィジェットの引き継ぎ** — FVで選んだ日付・時間・人数を下部フォームへ転記してからスクロールし、
  最初の未入力欄（お名前）へフォーカスを移します。同じことを2回入力させません
- **数字の見た目** — Cormorant Garamond の既定はオールドスタイル数字で、価格の桁が揃って見えません。
  `font-variant-numeric: lining-nums` で切り替え、カウントダウンには `tabular-nums` も併用して
  秒ごとの横揺れを止めています
- **タブのキーボード操作** — WAI-ARIA の作法に沿って、選択中のタブだけを `tabindex="0"` にし、
  左右キーで移動できるようにしています
- **アクセシビリティ** — `aria-expanded` / `aria-selected` / `aria-live` の付与、
  全画像への代替テキスト、SVGへの `<title>` / `<desc>`、`prefers-reduced-motion` でのアニメーション無効化
- **フォールバック** — JavaScript が動かない環境では、`no-js` クラスを手がかりに
  AOS の透明化を打ち消し、3つのタブをすべて展開し、カウントダウンをオープン日の表示だけに差し替えます
- **パフォーマンス** — FVの画像だけ `fetchpriority="high"`、それ以外は `loading="lazy"`。
  スクロールイベントは `requestAnimationFrame` で間引き

## 注意事項

- 店名・住所・電話番号・メニュー・価格・オープン日はすべて架空の設定です。実在の店舗とは関係ありません。
- 掲載写真はイメージです。記載のメニューや店舗とは関係ありません。
- 「宴会のお見積り」は設定した価格にもとづく試算表示で、実在のサービスではありません。
- フォームは送信処理を持たないデモです（送信ボタンで完了メッセージのみ表示）。
- 周辺図は架空の店舗位置を示す簡略図です。実際の地形とは一致しません。
